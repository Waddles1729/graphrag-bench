# Service catalogue

Every service we run in production. If it is not on this list it is not a
service: it is a job, a library, or something somebody forgot to write down.

- catalog-search
- checkout-api
- fraud-scoring
- identity
- invoicing
- ledger
- notify
- pricing
- reporting
- warehouse-sync

Ten in total. Ownership is recorded on each team's page rather than here, so
that a transfer is one edit and not two. Dependencies are recorded on each
service's own page, for the same reason.

## Adding a service

Open a pull request against this page and the owning team's page in the same
change. A service that appears here with no owner will be picked up in the
weekly review and, if it still has no owner a week later, turned off.
